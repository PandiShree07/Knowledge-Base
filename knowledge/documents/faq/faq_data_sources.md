# FAQ: Data Sources

Use documents for policies, definitions, and process explanations. Use MySQL for counts, lists, totals, and specific structured records. Use both when a question asks to apply a policy to structured records. If a source is unavailable or has no matching data, explain the limitation rather than filling the gap with assumptions.
