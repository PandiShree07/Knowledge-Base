# FAQ: Remote Work Setup

Use an approved device, keep operating-system and security updates current, lock the screen when away, and use approved secure connectivity. Keep confidential work out of public view and avoid unapproved cloud storage. Confirm meeting availability with the team and record attendance accurately according to the local process.
