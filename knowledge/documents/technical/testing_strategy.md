# Testing Strategy

Unit tests cover small isolated behaviors; integration tests verify interactions between components and external dependencies; end-to-end tests validate critical user workflows. Tests should be deterministic, maintainable, and meaningful. Regression tests should be added for fixed bugs. Use synthetic or anonymized data in tests and avoid embedding production credentials or personal information in fixtures.
