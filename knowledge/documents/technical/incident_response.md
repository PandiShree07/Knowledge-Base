# Security Incident Response

Report suspected security incidents promptly through the approved incident channel. Examples include exposed credentials, lost devices, unexpected data access, malware alerts, and accidental disclosure. Preserve relevant evidence, avoid deleting logs, and do not investigate beyond your authorization. Responders assess severity, contain impact, coordinate communications, and record follow-up actions. Lessons learned should result in tracked improvements.
