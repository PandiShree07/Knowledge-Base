# Logging and Monitoring

Logs should capture timestamps, operation names, correlation identifiers, outcomes, and sanitized error context. Avoid logging passwords, API keys, authentication tokens, or unnecessary personal information. Monitor latency, error rates, queue depth, and dependency health. Alerts should have an owner and a clear response action. Retain logs according to operational and legal requirements.
