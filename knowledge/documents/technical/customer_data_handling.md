# Customer Data Handling

Customer information should be accessed only for approved work and shared only with authorized recipients. Avoid unnecessary exports, use approved storage, and remove temporary copies when no longer needed. Verify recipients before sending files and use secure transfer mechanisms for sensitive data. Report accidental disclosure promptly.
