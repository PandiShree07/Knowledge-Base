# Code Review Guidelines

A code review should check correctness, readability, test coverage, error handling, compatibility, and security implications. Reviewers should focus on actionable issues and explain why a change matters. Pull requests should be small enough to review effectively and include context, testing notes, and relevant screenshots or logs when useful. Approval does not replace automated testing.
