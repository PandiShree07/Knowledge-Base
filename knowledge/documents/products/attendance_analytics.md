# Attendance Analytics

Attendance records include a date, employee, status, hours worked, and work mode. Reports should define the date window and the meaning of each status. A remote work mode is not the same thing as an absence status. When comparing teams, use consistent time ranges and avoid drawing performance conclusions from attendance alone.
