# Project Tracking Module

Project records include a name, department, owner, status, priority, start date, target date, and budget band. A project marked completed should be treated differently from one on hold or in progress. Delivery summaries should include the time period and acknowledge that target dates can change. Budget bands are synthetic categories in this demo dataset, not financial statements.
