# Leave Management Module

The leave management module represents requests with employee, leave type, date range, number of days, and status. Status values in the demo dataset include approved, pending, and rejected. Reports should distinguish requests from approved leave. Policy rules explain how requests are handled, while the database provides counts and individual records.
