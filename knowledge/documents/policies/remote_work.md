# Remote Work Policy

Remote work is based on role suitability, team coverage, information-security requirements, and manager approval. Employees should remain reachable during agreed core hours, keep calendars accurate, and document decisions in shared work systems. Confidential information must be handled on approved devices and networks. Public Wi-Fi should be avoided unless a company-approved secure connection is used. The attendance table records work modes such as office, remote, and hybrid; use database records for counts rather than this policy document.
